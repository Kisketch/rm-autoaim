# 遮挡后的重关联（B-02）

两台机器人相向通过，A 在最接近时被遮挡 3 / 6 / 12 帧，再出现时统计它的观测
有多少被“另一台机器人的轨迹”抢走。关联逻辑同 `src/target.cpp`（贪心最近邻 + 门限）。

## 结论

- 重见时被抢走：fixed 0% vs scaled 0%。
- **遮挡越久、间距越近，越容易被抢**：这正是真实比赛里两台机器人贴身时的场景。
- 门限缩放只能缓解，不能解决——因为重见瞬间“离得近”这件事本身就是错的证据。
- 正确做法：给轨迹维护速度，重见时比较**速度一致性**（|v_obs − v_track| < 1.5 m/s），
  不一致就新建轨迹而不是接管；以及遮挡期间用预测位置继续外推，而不是让轨迹饿死。

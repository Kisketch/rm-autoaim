# 命中落点的余量（C-02）

每发按打在装甲板上的横向偏移 `off_u` 统计（0 = 板中心，1 = 板边缘，单位是半宽）。

- 命中 2305 发，|u| 中位 **0.35**，均值 0.40
- 未命中 1173 发，|u| 中位 1.48（越小说明越是擦边）

| \|u\| ≤ | 命中占比 | 未命中占比 |
| --- | --- | --- |
| 0.25 | 39.0% | 9.0% |
| 0.50 | 64.6% | 9.4% |
| 0.75 | 84.8% | 10.2% |
| 1.00 | 99.6% | 13.1% |

## 结论

- 命中的落点中位偏移 0.35 半宽：**有余量但不宽裕**——超过 3/4 半宽才算“擦边命中”的只占 15.2%。
- 未命中里 9.4% 落在 0.5 半宽以内，说明大多数打偏**只差一点点**，和之前 `docs/miss_analysis.md` 的结论一致（40–49% 只出界半个板宽）。
- 这意味着：把系统误差再压 10–20% 就能把这批擦边球变成命中，收益比调开火窗口大；
  而压误差的方向是标定精度、时间戳、yaw 观测，不是参数。

*`off_u` 由虚拟射击判定给出，单位是板半宽。*
